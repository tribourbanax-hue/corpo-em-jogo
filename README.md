# Corpo em Jogo — Anatomia

Jogo de estudo de Anatomia (técnico de enfermagem): offline, feito para celular, sem cadastro.
Repetição espaçada, álbum de figurinhas, simulado com nota e trilha de cada sistema do corpo.

**Jogar:** abra o `index.html` (ou o link do GitHub Pages).

## Trilhas
Ossos e Locomotor · Sistema Nervoso · Digestório · Cardio e Circulatório · Respiratório e Renal · Imunológico · Reprodutor.

## Como editar / recompilar
O jogo é um único `index.html` gerado a partir de `src/` (banco de questões, figuras e app) e das imagens de `img/`.

```
node build.js
```

As questões ficam em `src/banco.js`; as imagens e marcadores em `src/figuras.js`.
